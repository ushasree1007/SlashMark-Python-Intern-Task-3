# SlashMark-Python-Intern-Task-3
APSCHE Python Internship – Task 3:

Task 3: Password Generator

Successfully completed Task 3 – Password Generator as part of the APSCHE Python Internship.

Developed a Python-based password generator application that creates secure passwords based on user-selected length. The program automatically generates random passwords using letters, numbers, and special characters.

Features:
• User can choose password length
• Automatic random password generation
• Includes uppercase, lowercase, numbers, and symbols
• Password strength checker (Weak / Medium / Strong)
• Interactive menu options
• Simple and user-friendly console output

Technologies Used:
• Python
• random module
• string module
• loops and conditional statements

Learning Outcome:
Through this task, I improved my understanding of:
             •Random value generation
             •String handling
             •User input processing
             •Conditional logic
             •Building real-time console applications
